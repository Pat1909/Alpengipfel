Campanile Letter / Letterspitze

Alpen › Österreich › Italien › Kärnten › Friaul-Julisch Venetien › Karnischer Hauptkamm

Campanile Letter / Letterspitze ist ein 2.463 m hoher Gipfel in der Gebirgsgruppe Karnischer Hauptkamm (Kärnten / Friaul-Julisch Venetien). Unter den 47.414 benannten Gipfeln der Alpen steht er nach der Höhe auf Rang 13.572, in der Gebirgsgruppe auf Rang 64 von 416.
