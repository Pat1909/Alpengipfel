Cima est di Finestra / Cime Est de Fenestre

Cima est di Finestra / Cime Est de Fenestre ist ein 2.686 m hoher Gipfel in der Gebirgsgruppe Seealpen (Piemont / Provence-Alpes-Côte d'Azur). Unter den 47.414 benannten Gipfeln der Alpen steht er nach der Höhe auf Rang 9.319, in der Gebirgsgruppe auf Rang 302 von 1.597.
