Cima di Test

Alpen › Italien › Piemont › Massif de Chambeyron

Cima di Test ist ein 2.620 m hoher Gipfel in der Gebirgsgruppe Massif de Chambeyron (Piemont). Unter den 47.414 benannten Gipfeln der Alpen steht er nach der Höhe auf Rang 10.547, in der Gebirgsgruppe auf Rang 157 von 345.
