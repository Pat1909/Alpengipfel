Rocher Gris

Alpen › Frankreich › Auvergne-Rhône-Alpes › Thabor-Gruppe

Rocher Gris ist ein 2.737 m hoher Gipfel in der Gebirgsgruppe Thabor-Gruppe (Auvergne-Rhône-Alpes). Unter den 47.414 benannten Gipfeln der Alpen steht er nach der Höhe auf Rang 8.411, in der Gebirgsgruppe auf Rang 91 von 190.

Wege und Routen

Bis auf den Gipfel ist kein Weg erfasst; der nächste Weg endet etwa 140 m entfernt. Der Gipfel ist vermutlich weglos.
