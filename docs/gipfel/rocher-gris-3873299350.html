Rocher Gris

Alpen › Frankreich › Auvergne-Rhône-Alpes › Belledonne-Gruppe

Rocher Gris ist ein 2.767 m hoher Gipfel in der Gebirgsgruppe Belledonne-Gruppe (Auvergne-Rhône-Alpes). Unter den 47.414 benannten Gipfeln der Alpen steht er nach der Höhe auf Rang 7.835, in der Gebirgsgruppe auf Rang 28 von 218.
